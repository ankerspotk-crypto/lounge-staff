# 📈 機能利用ログ のテスト

```bash
node tests/usage/run.js
```

`usage.gs` / `usage_catalog.gs` を**実物のまま**読み込み、GAS API（CacheService・SpreadsheetApp・
シート）をモックして走らせる。本番シートにもテストシートにも1セルも書かない。

⭐写経禁止＝ロジックをテスト側にコピーしない。実コードを `new Function` に流し込んでいるので、
`usage.gs` を直したらテストは自動的に新しい実装を見る。

## 何を守っているか
- ポーリング（30秒ごとの `getKioskLoadAll` 等）を統計に混ぜない
- 閾値未満ではシートに書かない＝軍師のタップに書き込みコストを乗せない
- 保険フラッシュを二重に呼んでも二重計上しない
- 死蔵リスト ＝ カタログ − 使用 − 計測対象外（この式が崩れると「消してよい機能」を誤判定する）
- 期間フィルタが効く／キャストは集計を見られない
- 新しく作った機能キーはカタログへ自動追記される
- ログが空でも落ちない（導入直後がこの状態）
