# 伝票管理（自社POS）の自動テスト

```bash
node tests/pos/run.js            # 全部
node tests/pos/run.js 01_calc    # 名前の一部で絞る
```

**本番シートにもテスト用シート(_TEST)にも1行も書かない。** GASもスプレッドシートも偽物で、
Node の中だけで完結する。営業中でも何度でも回してよい。

## 作りの肝

- **ロジックを写経しない。** `gunshi.html` の `BM_*` ブロックと `コード.js` の POSブロックを
  文字列マーカーで**そのまま切り出して** eval する（`lib/extract.js`）。
  写した瞬間から本物とズレる＝一番危ないテストになるため。
- **行番号で切らない。** マーカーが消えたら「どこが動いたか」を明示して落ちる。
- **パターンは1か所** ＝ `patterns.js`。ここに1件足すと計算一致・不変条件の全部に自動で乗る。
  新しい料金ルールや支払い方を入れたら、まずここに1行足す。
- **未決(`t.known`)** ＝ 仕様と実装がズレているが**まだ直していない**もの。赤くはしないが必ず一覧に出す。
  直したら `t.known` を `t.ok` に変える。「いつも赤いテスト」を作らないための逃げ道。
